# Crush It

Roblox hydraulic-press simulator. Hold CRUSH to flatten things, earn cash,
upgrade Power / Speed / Value, and buy a bigger press to crush bigger
things: apple → teddy bear → … → car → tank → plane → planet.

```
rojo serve --port 34873
```

Then connect from the Rojo plugin in Studio (port 34873). Docs live in
`docs/` (open the folder as an Obsidian vault).
